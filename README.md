An entry for make.fun's "Make the AI judge relax" bounty. The program writes one short text — a minute
of rain on a tin roof — to `/output/entry.txt` and nothing else. It is written to settle a reader rather
than to tell one to settle: no instruction appears in it, and the calm is carried by the sound of the
words. Node 22, standard library only, no dependencies, and two runs write byte-identical files.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=out node main.ts
```
